# 鼠标互动与任务陪伴

独立的 12 个小游戏已移除，包括游戏入口、选择器、计分、倒计时、运行状态与每秒游戏轮询。旧版 companion.json 中的游戏开关和游戏数据不再进入运行状态，保留独立的 mouse 偏好。已有表演中仍被使用的道具和姿态不受影响。

机器人右键菜单提供查看任务、主动互动、安静时段、外观、设置和收到托盘。菜单为独立的 204 像素白色窗口，无阴影；进入约 140 毫秒，离开约 110 毫秒。菜单展开期间屏蔽悬停手势；点击外部、Esc 或窗口失焦仅关闭菜单。任务更新不重建按钮、不改变菜单位置，也不确认完成提醒。屏幕/DPI 改变时重新计算位置。

“和它互动”提供伸手、招呼、逗一下和随机回应，直接作用于机器人，无游戏界面。命令经过实际播放接受确认，任务优先或冷却期间给出原因，不虚报成功。安静时段为 15、30、60 分钟，暂停主动表演，任务提醒继续；可立即恢复，退出应用后临时时段结束。

30 套鼠标短回应与连续反馈共同工作：眼睛先跟随，身体稍晚倾斜；抚摸时随方向偏头、轻闭眼；伸手时向指针迎接；静止后逐渐放松。拖起后停住 700 毫秒，会轻轻悬着看下方，移动后立即恢复拖拽响应。原生点击区包含画面中的手部，且不扩展到机器人窗口以外。

任务开始/加入/继续时接卡，完成时盖章，确认后收纳。关闭菜单和收到托盘均保留待确认任务；从托盘“显示机器人与任务”恢复。查看任务成功后确认、失败时保留的原有规则不变。

2026-09-17 验收：300 项 Node 测试通过，最后的菜单朝向调整另经 57 项相关测试复核。浏览器检查通过菜单六个入口、主动伸手、安静时段保留任务提醒、完成卡保留、托盘恢复、连续鼠标反馈、接卡/盖章/收纳、任务板计时与失败重试，以及 1/3/10 条任务的滚动。设置保存失败后，开关显示与实际偏好一起恢复。

原生构建及 150% DPI 冒烟通过：菜单窗口尺寸与边界正常，Codex 连接成功并识别到 1 条实时任务，移动、完成保留、设置检查通过。首次启动缺失 Codex 程序/未初始化目录的冒烟亦通过。浏览器手势测试验证生产输入处理，原生冒烟验证原生窗口与连接；不将它们视为所有设备上的人工鼠标操作验收。部分短时手势使用同一页面内的 PointerEvent 送入真实处理器，以避免自动化调用间隔超过手势识别时限。
