# 保留的互动能力

本轮只保留鼠标互动、12 种短时互动和机器人操作任务面板三个方向。原来新增的陪工动作、专注台灯、沙漏、任务便签、关注旗标、复制链接道具与六种生活空间已从界面、调度和新增表演库移除。应用原有任务列表上的复制链接与查看任务操作不受影响。

鼠标互动包含摸头、连续轻点、绕圈、快速经过与拖拽落地／触边反馈。可在“陪伴”设置中关闭；小互动入口为任务板顶部的互动图标。12 种玩法各为 18–25 秒，支持鼠标及键盘，任务发生变化会打断当前游戏。

任务卡在新任务开始、加入、继续时接过，在完成时检查并盖章，用户确认完成后收纳。卡片仍遵守原有完成提醒的持久确认、成功打开后清除与失败保留规则。任务事件优先于鼠标及游戏动作；减少动态模式保留语义反馈但压缩表演。

旧版 `companion.json` 可读取，其中不再使用的生活空间和道具数据不会进入运行状态，且不会再显示提醒。更改鼠标或互动偏好时仅写入保留字段。不主动删除用户本地文件。
