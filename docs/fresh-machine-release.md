# Windows 新机连接与公测验收

## 支持边界

当前为 Windows x64 公测候选版，使用 Tauri 2 / 系统 WebView2。最终用户不需要 Node、Rust、Git 或本仓库。需要用户自己的 Codex 桌面端及可用的 Codex CLI/app-server；Meta Bot 不代为登录，不要求 API Key，不是官方配对插件。

安装器在缺少 WebView2 时下载引导安装；离线机器必须预装微软 WebView2 Evergreen Runtime。当前未签名，不能宣称没有 SmartScreen 提示。不得要求用户关闭安全软件。仅有 Codex CLI、远程/云端任务、不同用户的数据目录不是已保证支持的场景。

## 首次使用

1. 在 Codex 中完成安装和登录初始化。
2. 安装并启动 Meta Bot，阅读第三方身份及本地数据说明。
3. 向导分别显示程序发现、数据可读性、查询通道、日志监听/轮询。
4. 路径不符时，选择可信安装目录中的 codex.exe 和正确的 Codex 数据目录，保存并重连。两个字段留空可恢复自动发现；不修改 Codex 配置。
5. 无进行中任务是正常空态。创建简短真实任务，观察开始、完成、查看正确任务、确认清除四项。
6. 点击“完成验证”是用户声明验收通过，不是程序自动证明深链接落点。可以跳过；设置中的“连接向导与修复”始终可重开。

通道连接成功不等于已订阅 Codex 桌面内部的全部事件。任务识别依赖 app-server 查询、本地日志和轮询；Codex 升级或改变日志格式后需要重新验收。没有证据时展示未知/离线，不用超时伪装任务完成。

## 隐私与诊断

Meta Bot 在当前用户 `.metabot` 下保存设置、任务元数据缓存、提醒状态和窗口位置。任务标题、项目路径可能进入本地缓存。它读取 Codex 的任务日志，不主动读取或导出 auth.json，不修改登录配置；Codex 子进程本身可能读取其配置并写自身运行记录。

“复制脱敏诊断”仅包含应用版本、平台、程序是否存在、数据目录是否可读、sessions 目录是否存在、连接状态、监听开关、向导状态。不包含文件路径、任务标题/ID、日志正文、Token 或原始错误。由用户自行分享，不自动上传。

卸载后的数据保留行为需要在干净系统实际验证；在此之前，不承诺卸载会清除缓存。需要清理时由用户备份后处理 `.metabot`，不可删除 `.codex`。

## 发布门槛（不能用本机测试代替）

| 场景 | 必须确认 |
| --- | --- |
| 干净 Windows 11 x64 + Codex，无开发工具 | 安装、启动、首次引导、完整真实任务闭环 |
| 未安装/未初始化 Codex | 有明确修复提示，UI 不永久卡死 |
| 缺少 WebView2，在线/离线 | 在线可安装；离线有可执行的预装指引 |
| 自定义目录、中文用户名、空格路径 | 自动检测或选择路径成功，取消选择不改设置 |
| 无任务、多任务、启动时已有运行任务 | 空态不报错，活动任务不漏检，不重播历史完成 |
| Codex 关闭、重启、升级 | 明确离线/未知，恢复后同步，无重复启动/完成提醒 |
| 权限不足、失效程序路径 | 失败原因可见，可修复，不能静默切错数据源 |
| 不同 DPI、双屏、屏幕边缘 | 向导/气泡可见，拖拽和查看可用 |
| 升级安装、卸载、重装 | 配置迁移、快捷方式、旧进程和数据保留策略正确 |

记录每台机器的 Windows 构建号、Codex 版本、WebView2 版本、安装包 SHA256、步骤和结果。所有真实新机项通过后才称为“新机已验证”。本仓库单元测试、模拟 UI 与本机隔离配置原生冒烟不能证明这些项目。

## 本次验收环境限制

开发机未发现 WindowsSandbox.exe；存在 vmcompute 服务并不能证明可用的干净 Windows 虚拟机。未经用户授权不安装系统组件、不变更虚拟化功能、不下载操作系统镜像。干净系统安装/卸载和离线 WebView2 测试仍属于发布阻断项。

## 可复跑的本机检查

```powershell
npm test
npm run check:native
npm run build:native
npm run test:native
npm run test:native -- --onboarding
npm run test:native -- --dpi
npm run size:native
```

`--onboarding` 在独立的 `.runtime/native-test-*` 中放入不存在的程序/数据目录，不改变用户 Codex 配置；验证未连接不会被误标为验证通过，修复向导可显示、跳过状态可保存。普通冒烟使用本机真实 Codex 查询和合成提醒数据，不会创建或执行真实 Codex 任务。

`test/onboarding-review.pw.js` 是模拟后端的浏览器交互检查；`test/onboarding-native-review.pw.js` 使用仅测试进程开放的本地 CDP 9226 端口，实际检查原生接口、恢复自动发现和重新连接。不可对含用户正式配置的进程运行该脚本。检查后关闭测试进程，不在发行版启用调试端口。
