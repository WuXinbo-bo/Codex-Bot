## 运行边界

1. 独立启动的 app-server 不保证收到另一 Codex 桌面实例的全部运行通知。按照官方 app-server 文档处理 `thread/status/changed`、`turn/started`、`turn/completed` 和 activeFlags，并以本地日志监听补充跨进程证据。没有通知也没有落盘证据的批准请求，不能保证即时感知。
2. JSONL 是版本相关的本地证据，不是稳定的跨进程推送契约。冷启动向后最多查找 8MiB，增量每次最多处理 8MiB；没有生命周期或尚未处理完时显示状态确认中，不推测任务完成。
3. 运行日志超过 120 秒无新写入会降为状态确认中，长时间无输出的正常工具也可能触发此保守状态。已观测为活跃的同一轮任务继续保留在进行中列表及计数中，但不宣称仍在运行；从未观测为活跃的未知历史不计入。已明确等待用户的任务不按此规则猜测结束。
4. 默认首批返回最多 100 条，只对最新 25 条、已跟踪/变化/有运行事件的任务及显式加载历史读取日志。已观测的运行或等待任务滑出列表仍跟踪。未读取历史显示状态确认中，不意味着全量历史均处于实时监控。
5. 默认工作轮询 1.5 秒、空闲 2 秒，另加单次查询耗时；日志变化优先触发刷新。手动刷新在采样期间收到变化时最多补做两次采样。每 5 分钟执行索引扫描修复，该轮可能较慢；不支持数据库参数的旧版本回退兼容查询。用户已有显式间隔配置继续生效，不静默覆盖。
6. “Codex 已连接”表示 Bot 的本地查询通道可用，不等同于 Codex 桌面窗口打开。查询失败后保留按来源标记的缓存，并使用退避重试。
7. 本机没有可用的已配对工作台服务，工作台真实在线链路未验收；隔离、断线、映射和打开目标使用测试夹具验证。工作台默认停用，配置后可在连接诊断中启用。

官方参考：https://developers.openai.com/codex/app-server/

## 生命周期动作与提醒（2026-09-08）

基线 `3335c3a`。TaskCenter 的快照只决定活动计数和状态灯；未读完成记录不再产生角标或常亮绿灯。独立 lifecycle 事件以来源、任务、轮次、类型去重，首次新鲜采样中的运行任务只轻量加入工作，常开期间的新任务播放开始动作；每项完成不依赖当前主任务。

动作控制器将同类短时事件合并，拖拽期间延后，快照刷新不会中断提醒；短任务已完成时取消尚未播放的开始提醒。新增接收任务、点头准备、交替敲键、递交结果、检查完成、收工放松 6 套活动，总计 38 套。工作活动计划间隔为 12–20 秒，悬停或更高优先级交互可延后。减少动态模式保留文字提醒。

提醒使用独立、不抢焦点、不截获点击的约 260 x 82 白色气泡，4 秒隐藏，不扩张 128 x 128 球体或原有活动任务对话框，不播放声音。多任务同时完成合并显示数量；完成后即使未读仍隐藏角标。

验证：127 项单元测试通过；真实连接样本返回 100 个任务、1 个活动任务、1 行列表，球体状态一致。原生生命周期注入验收确认最后任务完成时 `count.hidden=true`、灰色 idle 灯、优先级 55 的完成动作和完成文字气泡同时出现。原生拖拽、点击与 150% 缩放验收通过。浏览器生命周期检查覆盖空闲、开始、其他任务仍运行时完成、刷新不中断、去重、拖拽延后和长标题布局。38 套活动逐帧检查共 629 个采样通过，无无效几何或球体越界；390px 移动端无横向溢出。递交结果与检查完成的摆动幅度根据渲染结果收敛。

原生复验：`npx cross-env METABOT_LIFECYCLE_TEST=1 npm run test:connection -- --user-data-dir=D:/ModelX/Meta-Bot/.runtime/lifecycle-verification`。生命周期注入仅在此测试开关下执行，先验证真实连接，再停止测试实例的桥接并注入测试快照，不修改 Codex 任务。浏览器复验使用独立会话运行 `test/lifecycle-review.pw.js`。

状态来源的时效边界不变：本轮没有把本地日志监听改成 Codex 桌面的权威推送通道，尚未到达 Bot 的事件不能提前提醒。

## 刷新一致性与紧凑对话框（2026-09-08）

定位到的直接原因是刷新竞争：Codex 在已有查询执行期间进入运行状态时，日志监听将来源标为 dirty，但手动刷新复用了尚未完成的旧查询并立即返回，界面因此显示“同步完成”却仍拿到旧快照。现在手动刷新先给 Windows 文件监听 180ms 合并窗口；若查询期间又收到变化，同一刷新最多补采两轮后才返回。轮询兜底调整为工作 1.5 秒、空闲 2 秒。

悬浮球主状态改为优先活动任务，旧的终态未读提醒不再覆盖“正在运行”。气泡收敛为 348 x 326 的白色半透明对话框，只列活动任务；完成与历史任务不进入列表。

验证：118 项单元测试通过，其中覆盖“自动查询期间任务刚启动、随后点击手动刷新”的竞争场景；真实 Codex 检查返回 100 个任务、2 个活动任务、2 行气泡任务，悬浮球与主状态均为 running，数据库查询样本 105ms。浏览器视觉检查覆盖活动/待确认/历史未知/完成切换、查看/复制/刷新操作与紧凑尺寸，无脚本异常。
