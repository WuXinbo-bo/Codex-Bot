# Meta Bot M1 Design Package

M1 已锁定为默认圆形、可连续变形的桌面任务伙伴。本目录是定妆和动态交互设计源资产，不是当前运行时资源。

视觉基线：`#02AD45` 绿色无描边弹性身体、白色几何眼白、黑色独立瞳孔、无嘴、按语义出现的可收纳线条手臂。核心识别来自眼神和动作系统，而不是装饰或固定表情贴图。

## Assets

- `M1_DESIGN_SPEC.md`：视觉、Rig、状态和动作合同；
- `meta-bot-m1-model-sheet.svg`：默认定妆、构造、手臂与小尺寸检查；
- `meta-bot-m1-expression-board.svg`：24 个核心神态；
- `meta-bot-m1-interaction-board.svg`：12 组交互动作序列；
- `meta-bot-m1-shape-motion-board.svg`：身体形变与状态映射。

参考图片只用于提炼眼白、瞳孔、眼睑的组合方法，没有复制其中的具体图形或排版。
