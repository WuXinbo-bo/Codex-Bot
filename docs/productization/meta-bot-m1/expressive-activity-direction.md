# Meta Bot：特殊表情、活动与变装设计方向

日期：2026-09-07

状态：首版活动系统已实现。现有 28 段可播放片段、8 类特殊眼形和六组变装接入状态与交互调度。以下保留设计方向；逐项验收结果见同目录 activity-verification.md，未列出的扩展细节仍属于后续调优建议。

## 角色定位

Meta Bot 是有自己小习惯的桌面搭档：认真做事，好奇，偶尔得意，被发现走神时有一点不好意思，也会主动找一点乐子。

保留绿色、无嘴、默认圆润身体作为识别特征。正常眼睛以圆眼为基础，但特殊情绪允许整只眼睛变成符号。身体可以压扁、拉长、侧翻、短暂变成圆角方形或缩成小团；每次变化都要服务具体表演，并能自然回到定妆。

丰富度来自“眼形、视线、姿态、手势、道具、节奏、情境”的配合。不能把增加随机表情数量当作完成标准。

   - 借鉴：同一个角色可以突破日常五官，脸、手、外观和附加效果共同表达情绪。

   - 官方文档列出爱心、气球、点赞、点踩、雨、彩纸、烟花和激光等反应，并关联明确手势或手动选择。
   - 借鉴：动作有明确触发，夸张效果是表演高潮，不需要一直播放。
3. LivingAI EMO 官方页面：https://living.ai/emo/
   - 官方介绍探索、受打断的反应、音乐与舞蹈、游戏、生日和节日活动。
   - 借鉴：角色有正在做的事情、会被打断、会恢复活动；时间与交互历史会影响行为。
   - 页面包含厂商对数量和智能能力的宣传及部分未来功能描述；本提案不把这些当作已独立验证的实现能力。

下列 Meta Bot 剧情、道具组合及调度数值是本项目的原创建议，不是对上述产品的功能复述。

## 当前实现为什么仍显单一

- 眼白几何仍统一来自椭圆路径；弯眼主要靠闭眼线表现，还没有真正的星形、爱心、旋涡等独立眼形。
- 当前表演共用 bob、tilt、wave 等振荡参数，虽然幅度不同，动作节奏仍容易相似。
- 缺少拿出、使用、收起道具的过程，无法形成“他正在做什么”的明确印象。
- 行为记忆主要用于表情去重，尚未记录一次活动做到哪一步，也没有专门的被打断反应。

## 眼睛的三个表现层次

| 层次 | 眼形与视线 | 用法 |
| --- | --- | --- |
| 日常五官 | 圆眼、竖椭圆、大小眼、豆豆眼、眯眼、弯月眼、单眼眨眼 | 持续工作、观察、倾听和日常互动 |
| 漫画符号 | 四角星、爱心、旋涡、挤紧的尖括号、短横线、短暂叉叉、泪汪汪眼 | 活动或互动中的短高潮 |
| 戏剧化脸部 | 眼睛缩成两点、先后变形、眼睛暂时消失后重开、隔着墨镜露出一只眼 | 惊讶、恶作剧、偷看、装酷和变装 |

特殊眼形不是在原来的椭圆上贴图：可以用整眼替换、瞳孔变化或短暂遮挡，但每段动作必须选定一种清楚的表达。

星形表示兴奋；爱心表示对用户的亲近；旋涡表示被转晕；短横线表示短暂无语；挤紧眼表示用力；泪汪汪眼用于夸张的撒娇或笑意。叉叉眼仅用于非常短的漫画式被晃晕，不能成为真实故障的常驻脸。

两只眼睛可以按剧情先后反应。例如先睁开一只偷看，发现用户还在，再睁开另一只。日常观察仍共享一个注视目标。

## 第一批重点打磨的 12 段活动

| 活动 | 起因与动作过程 | 眼形高潮 | 收尾 |
| --- | --- | --- | --- |
| 戴眼镜研究 | 工作中偶尔拿出眼镜，戴歪，扶正，凑近看一张小卡片 | 一大一小的眼睛，镜片轻闪 | 折起卡片，摘下眼镜继续工作 |
| 被发现走神 | 空闲时身体晃悠悠，视线飘开；鼠标靠近后突然停住 | 豆豆眼停顿，再认真睁眼 | 把手背到身后，恢复端正姿态 |
| 认真想一想 | 歪头，摸下巴，视线从一侧缓慢移到上方 | 短暂星星眼 | 自己点一下头，恢复观察，不伪装成任务已解决 |
| 转晕后扶正 | 拖拽画圈后身体滞后，松手时摇摆两次 | 旋涡眼 | 双手扶住自己，停一下，单眼眨眼后恢复 |
| 举起后挣扎 | 长按进入准备，拖动时手臂追上身体，偶尔向下探手 | 小瞳孔大眼，短暂挤紧眼 | 轻放舒展；快速释放做明显回弹 |
| 弹簧伸懒腰 | 空闲一段时间后缩成小团，举手向上伸展 | 挤紧眼 | 一侧手先放下，身体两次递减回弹 |
| 偷戴墨镜 | 拿出墨镜戴上，身体侧倾摆造型 | 墨镜滑下后露出一只眼 | 扶正镜框，再收起；被打断则半途摘下 |
| 小魔术 | 戴上魔术帽，向帽内看，轻点帽檐 | 帽内冒出小星星时变星形眼 | 接住掉下的小星星，放回帽中，鞠躬 |
| 小舞步 | 空闲时左右两拍，第三拍手慢半拍，停顿后补上 | 交替眨眼，最后弯眼 | 自己满意地点头，恢复站姿 |
| 困到点头 | 长时间空闲后抱小枕头，头缓慢下沉又抬起 | 短横线眼，再闭眼 | 鼠标靠近时先睁一只眼，藏好枕头再抬手 |
| 完成后的得意 | 真实任务完成时先愣一下，再挺起身体、披上短披风 | 星星眼或单眼眨眼 | 敬礼，披风飘落后收起，进入安静状态 |
| 等你回应 | 需要输入时先看向任务面板，举手，放下，再轻轻探头 | 大眼期待，短暂泪汪汪变体 | 持续等待时恢复自然观察，避免循环催促 |

每段活动首版只精修一条完整动作，再增加第二条反应变体。不同活动必须有不同的轮廓和节奏，不能全部套“摇头、上下弹、挥手”。

## 第二批可扩展的日常活动

- 抛接一个小方块：先用眼追踪，手慢一点接住，最后藏到身后。
- 折小纸飞机：折错一次，眯眼检查，重新折好，举起来欣赏。
- 平衡练习：顶一个小方块，左右修正身体，掉下时接住。
- 捧杯休息：抱着小杯取暖，眼睛变柔和；不需要添加嘴部或饮用动作。
- 整理自己：抚平被拖拽拉歪的身体，拍拍两侧，再检查手的位置。
- 模仿指针：鼠标缓慢左右移动时跟随，停住后多晃半拍。
- 小侦探：戴帽子，拿放大镜观察自己的手，再偷偷看用户。
- 无声鼓点：轻拍两下身体，顿一下，再补一个夸张的收尾。
- 工作间歇：把虚构的小卡片叠齐，碰歪后重新码好；不显示虚假实际进度。
- 小画家：戴贝雷帽，画一颗小星星，退后端详，擦掉重画一笔。
- 雨天小剧场：用户选择时撑一把小伞，试探地伸出手；没有天气数据时仅作为主题活动。
- 节日礼物：使用本地日期判断明确节日，打开小礼盒、试戴帽子、鞠躬。

## 六组变装及其专属动作

| 主题 | 视觉资产 | 必须配套的动作 |
| --- | --- | --- |
| 小研究员 | 圆眼镜、小卡片 | 戴上、推镜框、凑近看、收起 |
| 装酷搭档 | 墨镜 | 戴上、侧倾、镜片滑落、露眼、扶正 |
| 小魔术师 | 高帽、小魔杖 | 探帽、点帽、接星星、鞠躬 |
| 小英雄 | 短披风 | 系好、挺身、敬礼、披风滞后摆动 |
| 瞌睡搭档 | 睡帽、小枕头 | 抱住、点头、被发现后藏起 |
| 小画家 | 贝雷帽、小画笔 | 拿笔、画一下、退后看、改一笔 |

换装要看得见“拿出、穿戴、使用、脱下”。配件跟随身体和手部锚点，手持物具有轻微滞后。原本眼睛被墨镜遮住时，禁止同时叠加完整爱心眼和旋涡眼；通过组合规则保持清楚。

## 行为的连续性与节奏

角色记住最近几段活动、当前活动阶段、被打断次数和最近交互时间。记忆首先保存在当前进程中，不需要为了动作丰富度引入额外在线服务。

- 第一次靠近：先转眼，再转身。
- 短时间第二次靠近：认出你，单眼眨眼或小幅挥手。
- 持续停留：从好奇到互动，可能递出小道具或比心。
- 连续快速逗弄：先跟随，再无语停顿，最后自己整理姿态；输入响应始终保持即时。
- 活动中被点击：用当前姿态接住输入；道具在约 150–250ms 内放下或收起。面板打开不能等待活动播完。
- 拖拽中：身体受力和视线优先，后台活动暂停；松手后先恢复平衡，再决定是否继续上一件事。
- 工作结束：根据真实状态触发庆祝。随机工作动作不能制造完成、错误、重连等信号。

首轮节奏调试建议：工作时每 7–12 秒出现一次短动作，每 35–60 秒才允许一次 2–4 秒的道具活动；空闲时每 12–20 秒出现一次 3–6 秒小活动。互动后的短时间内提高亲近反应概率，然后自然回落。同一完整活动至少间隔数分钟，稀有变装只做低频惊喜。数值需通过真实长时间回放调整，不作为固定审美标准。

## 实现方案

继续使用现有 SVG 渲染器与桌面交互系统，并把表演能力分成四部分：

1. 眼形绘制：普通眼睛保留眼白、瞳孔和裁剪；符号眼采用专用几何。可匹配拓扑的形状做路径插值，其余借助眨眼、手遮挡或短交叉淡入完成切换。
2. 动作片段：每段都有准备、主动作、停顿、二次反应和收尾；身体、眼睛、手势分别有关键帧时间，不再只依赖同一周期的正弦摆动。
3. 配件绑定：头部、左右手、身体前后有明确锚点，处理遮挡、拿取和跟随。
4. 活动调度：根据真实状态、交互历史和冷却选择活动，并保留活动阶段和打断恢复信息。

眼睛先动、身体随后、手和道具稍晚到达。到达后可以停一拍，做出第二个反应，这些时间差要按每段剧情编排。

原有右上状态点、右下任务数量和点击区域保持独立。角色可以在内部翻滚、伸展和换装，原生窗口不跟随表演缩放或漂移。首先保证 128px 原生大小清楚，再看放大的审美效果。soft 模式减少位移与剧烈特效；reduced 模式提供代表性静态姿态并停止连续活动。

## 下一轮验收

- 先完成 12 段重点活动的实际渲染样片，逐段看正常速度和慢放。
- 单帧应能区分至少八类主要情绪；整段应能看出角色正在做什么。
- 眼形切换没有游离瞳孔、突兀闪白或残留黑点；道具不穿过眼睛和手臂。
- 一次展示一件主要事情，特殊眼形、变装和特效有主次。
- 检查不同缩放比例下的身体、配件和角标边界。
- 连续打断、快速拖放、面板开关和低动态偏好均须实际验证。
- 回放十分钟工作和十分钟空闲，记录活动重复、间隔和占时；工作状态仍可一眼辨认，空闲状态有活动但不一直循环同一段。

实现范围以完成这些可见活动为准；没有完成的素材、调度或片段不能用一个新表情名称代替。

## 2026-09-08 调度修订

在 28 段首版基础上增加左右对照、沿线推演、归整资料、放大检查，共 32 段、123 个阶段。工作池从 3 种增至 7 种。首次完整活动在启动 18 秒后等待下一次调度；工作活动候选间隔调整为 24–40 秒，仍保留同片段 180 秒冷却。

举起片段保留 1.3 秒，期间更新身体受力和目光，结束后采用最新拖动速度；急转、绕圈和释放可即时覆盖。接近区域与球体区域属于同一次拜访，离开至少 800ms、30 秒内返回才触发再次见面。

日常活动被交互打断时保留当前阶段和剩余时间；15 秒内、同一任务状态、指针离开且面板关闭后接续。任务变化、低动态模式或停止会清除续播记录。模仿需要真实指针样本，随实际方向改变视线和身体倾斜，工作中不触发。

面板为所有已观察到的任务状态变化分配事件标识，包括当前被高优先级任务遮住的任务。提醒完成播放后才记为已传达；缓存不启动庆祝，缓存变为新鲜状态后可以提醒。重复查看不再庆祝，新的运行周期仍可庆祝。持续待处理或失败保留低频重复提示，打开面板时暂停重复。
