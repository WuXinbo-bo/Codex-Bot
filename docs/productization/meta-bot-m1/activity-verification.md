# 活动系统验收

更新日期：2026-09-08（首版：2026-09-07）

## 已实现

- 32 段活动、123 个阶段：首版 28 段加左右对照、沿线推演、归整资料、放大检查。
- 8 类符号眼：星形、爱心、旋涡、挤紧、短横线、叉叉、豆豆、泪汪汪。叉叉眼保留在预览库，默认运行不使用。
- 六组变装与 19 种配件，具有头部、脸部、身体与手部锚点。
- 工作池包含 7 种安静活动；完成、失败、等待输入由真实状态与任务事件触发。
- 提醒优先于活动；拖拽时延后提醒，松手后接续；状态改变会取消过时活动。
- 举起后 1.3 秒完整反应不被普通移动事件覆盖，速度与目光继续更新，急转和放下仍即时响应。
- 接近、进入球体视为同一次拜访；离开至少 800ms 后、30 秒内返回才打招呼。
- 日常活动在同一上下文中保留当前阶段和剩余时间，15 秒内待指针离开、面板关闭后续播；过期、状态变化、低动态模式或停止会清除。
- 指针模仿读取真实移动样本，改变目光和身体倾斜；工作中不触发。
- 提醒播完后记录已传达事件，切换任务再返回不重复庆祝；面板也跟踪未展示任务的状态变化，观察到再次运行后可以重新提醒。缓存转新鲜状态不会漏掉提醒。
- 后台轮询不再触发刷新表演；手动刷新与连接恢复仍有反馈。
- 同时存在运行和需要处理任务时，面板优先显示需要处理任务。
- 空闲活动可由托盘选择；礼物仅在明确日期或手动请求时出现，雨天剧场仅手动触发，不读取或猜测真实天气。
- 动作预览页提供活动选择、播放、Codex 状态切换及所有关键帧，支持真实指针操作和四条交互链演示。

## 验证

- 86 项 Node 测试通过，覆盖活动几何、配件引用、提醒身份、缓存、打断、低动态偏好及十分钟工作/空闲模拟。
- Playwright 播放全部 32 段活动，检查 545 个采样帧，无无效几何、无身体出界和页面脚本错误。
- 1040px 桌面预览及 390px 移动预览检查通过，无横向溢出。
- 实际应用页面验证按压、长按、快速拖拽、减速、急转、释放、刷新、完成和两档动态偏好，固定角标不位移。
- Electron 150% 缩放交互检查通过：拖拽位置准确，面板可打开/关闭，连续位置更新后原生尺寸保持在现有 1 DIP 容差内，两个角标在视口内。
- 浏览器实际交互链通过：举起、续播、再次拜访、提醒去重、真实鼠标模仿。面板真实 DOM 验证通过：待处理优先级、返回去重、被遮挡任务再次运行、缓存转新鲜状态。
- 固定种子 42 的十分钟工作模拟中，7 种工作活动全部出现，首段约 22.8 秒出现，focus 姿态占约 71.37%。这是该次模拟结果，不是普遍平均值。
- Electron 启动检查通过。

回归入口：`npm test`、`npm run test:interaction`、`npm run test:desktop`；Playwright CLI 分别执行 `test/m1-activity-review.pw.js`、`test/m1-visual-review.pw.js`、`test/m1-interaction-review.pw.js`。桌面检查应使用独立 `--user-data-dir`。交互链检查必须在页面加载前安装测试时钟，因为控制器创建时会保存计时函数。

## 当前边界
