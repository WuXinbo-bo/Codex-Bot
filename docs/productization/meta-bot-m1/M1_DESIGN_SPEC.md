# Meta Bot M1 定妆与动态交互规范

版本：M1 / 2026-09-07

## 角色锚点

Meta Bot M1 是一个默认呈圆形的弹性数字生命。它理性、专注、可靠，但身体会泄露好奇、疲惫、小得意和短暂紧张。

M1 的核心差异不是颜色，而是：

- 白色眼部容器可以独立拉伸、切角、弯曲和错位；
- 黑色瞳孔独立跟随光标、速度和关注方向；
- 身体在圆、圆角方、扁圆、纵向胶囊和不对称软形之间连续变换；
- 不设置嘴巴；情绪必须由眼白、瞳孔、身体姿态和手势共同完成；
- 两条线条手臂平时收纳，仅在有表达价值时出现；
- 同一任务状态拥有多个带上下文条件的表现，而不是固定一个表情。

## 视觉规格

| 项目 | 规格 |
| --- | --- |
| 默认身体 | 104×104 圆形，位于 128×128 画布中心 |
| 身体主色 | `#02AD45`（RGB 2, 173, 69） |
| 眼白 | `#F3F6F2` |
| 瞳孔/线条手臂 | `#181B20` |
| 注意 | `#F4BE4F` |
| 异常 | `#F0645D` |
| 身体描边 | 无；主体使用纯色剪影 |
| 手臂 | 4px 圆头线，必要时出现 |
| 安全边距 | 8px |

颜色不作为唯一状态信号。所有重要状态必须同时改变眼神、身体姿态或手势。

## Rig 分层

眼白和瞳孔必须分层，不能继续使用单层黑色眼环表达全部情绪。

## 身体形变语法

身体使用面积近似守恒的超椭圆或等价贝塞尔路径：

```text
abs(x/a)^n + abs(y/b)^n = 1
```

| 形态 | 参数倾向 | 使用场景 |
| --- | --- | --- |
| `rest-circle` | n≈2.1 | 默认、普通运行 |
| `focus-oval` | a>b, n≈2.7 | 专注、扫描 |
| `tense-square` | n≈4.4 | 紧张、长按锁定 |
| `surprise-capsule` | b>a, n≈2.3 | 惊讶、突然新增任务 |
| `fatigue-flat` | a>b, y 下沉 | 疲惫、长时间运行 |
| `impact-squash` | 接触侧局部压平 | 碰边、重落地 |
| `curious-lean` | 中心偏移、左右不对称 | 好奇、接近光标 |

任何形变均不得带动右上状态锚和右下任务锚离开其安全区。

## 表情组合维度

每个表现由以下参数组合，而不是静态图片：

```js
{
  shape,
  eyeWhites: { left, right },
  pupils: { left, right },
  lids,
  arms,
  fx,
  timing
}
```

首发表情板定义 24 个关键神态：中性、平静、专注、深度专注、向左扫描、向右扫描、好奇、思考、自信、坚定、愉快、小胜利、惊讶、困惑、谨慎、紧张、受挫、重试、疲惫、释然、需要输入、等待、完成、失败恢复。

### 无嘴表达约束

- 任何尺寸和状态均不得出现嘴线、口腔或以装饰线暗示嘴巴；
- 绿色身体不得使用黑色外描边，轮廓只由纯色剪影和形变建立；
- 眼白决定眼睑压力和情绪类别，瞳孔决定注意目标与反应强度；
- 相近神态必须至少在两个通道上不同，例如瞳孔聚散 + 身体倾斜；
- 手臂只在有动作语义时出现，不能成为持续噪声；
- 强调线只能出现在身体外侧，并与面部保持明确间距。

## 动作交互合同

首发动作板定义 12 个序列：

| 序列 | 输入证据 | 关键变化 |
| --- | --- | --- |
| 接近 | 光标进入感知半径 | 最近的眼睛先捕捉，再整体注视 |
| 悬停停留 | 0.2/0.8/2.5 秒 | 看见 → 好奇 → 轻微贴近 |
| 按压 | mouse down | 身体压下，瞳孔看向按点 |
| 长按锁定 | hold ready | 圆形变圆角方，双手扶住身体 |
| 慢速拖拽 | 低速移动 | 身体轻拉伸，单手抓取方向 |
| 高速拖拽 | 高速移动 | 瞳孔和内核产生滞后，双手后摆 |
| 急转 | 方向夹角突变 | 瞳孔短暂错位，一只手稳住身体 |
| 画圈 | 累计转角超过阈值 | 跟随一圈后短暂晕眩，有冷却 |
| 碰边 | 约束位置变化 | 接触侧压平，手掌撑住边界 |
| 释放落地 | release velocity | 轻落/重落两档压缩与恢复 |
| 打开面板 | panel visible | 一只手把面板方向推开并展示 |
| 刷新恢复 | manual/slow/recovered | 扫描、寻找、重新接通信号 |

## 运行态表现库

运行态占产品使用时间最高，首发至少包含 12 个表现：

```text
focus_scan, deep_focus, context_sort, micro_confirm,
idea_trace, double_check, multi_split, external_wait,
fatigue_reset, refocus, cautious_retry, quiet_progress
```

后台快速刷新成功不得重置运行态行为计时器。运行态使用带种子的加权随机袋、最近四次去重和独立冷却。

建议节奏：

- 眨眼、呼吸、瞳孔修正：2–7 秒；
- 轻量工作神态：8–20 秒；
- 明显工作动作：25–60 秒；
- 稀有签名动作：90–240 秒。

## 人格边界

Meta Bot 可以对任务表现疑惑、疲惫或受挫，但不能对用户表现蔑视、嫉妒、厌恶或攻击。失败动画最终必须回到稳定状态，不能持续制造焦虑。

## 实现边界

M1 SVG 资产应由自有渲染器消费。新实现不得复制第三方眼环点集、球面投影、彩带、撒花或粒子代码。行为导演、形变生成、眼部 Rig 和手势 Rig 均建立独立数据合同。

## 验收目标

- 128px、64px 和 32px 下眼神仍可辨；
- 默认剪影是圆形，但紧张圆角方、疲惫扁圆和惊讶纵向形态能明确区分；
- 5 分钟运行中出现 4–7 种可辨行为且不连续重复；
- 按压反馈小于 100ms；
- 状态锚和任务锚在任何形变下不越界、不脱离；
- `reduced` 模式只保留离散眼神、眼睑和轮廓切换，不连续移动身体或手臂。
