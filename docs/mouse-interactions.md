# 鼠标互动

本次新增 30 套手工编排的短回应，分为十类。每套约 2–3.5 秒，沿用现有眼睛、圆润身体和手臂，不增加嘴巴。性格节奏可微调播放速度。工作状态使用收敛的动作；任务提醒和拖拽优先。

## 动作与触发

| 类别 | 如何触发 | 三套回应 |
| --- | --- | --- |
| 靠近 | 靠近后稍停，避免擦过就演戏 | 侧眼探头、转身招手、悄悄凑近 |
| 抚摸 | 头顶缓慢来回，真实移动超过约 0.42 秒 | 顺手歪头、放松成软团、换一边继续摸 |
| 轻点 | 点击身体；快速经过也有躲闪 | 脸颊回弹、捂脸偷看、躲开再探回来 |
| 挠痒 | 身体两侧快速反复移动；连续轻点 | 缩起来护住两侧、左右躲、护住后偷看 |
| 抓指针 | 指针在身边停约 1.3 秒 | 悄悄伸手、合手检查、装作不在意再试 |
| 回来 | 离开 0.8–20 秒后重新靠近 | 左右找、假装没看见、探头迎接 |
| 模仿 | 身体下方左右或上下反复移动 | 跟着歪头、慢半拍、做反后纠正 |
| 绕圈 | 指针绕身体大半圈，持续至少约 0.65 秒 | 眼神跟随、转动后站稳、扶住自己再找你 |
| 落地 | 拖拽后放下，根据速度和边缘位置选取 | 轻落舒展、快速落地整理、扶住边缘 |
| 招呼 | 停在手旁等邀请、点击抬起的手、离开 | 邀请击掌、碰手后仰、挥手目送 |

## 调度约定

- 同类普通动作随机选取，排除最近两套；三套轮换后再重复。落地、击掌等明确语义按情境选择。
- 同类冷却通常 6.5 秒，工作中 12 秒，招呼 9 秒；普通回应最小间隔 1.2 秒。
- 抚摸、抓指针和模仿支持短链，最多三段，9 秒内无人继续则结束。抚摸后可以歪向另一侧邀请继续；击掌邀请最多等待 6.5 秒。
- 指针静止不会被当成抚摸；一次停留不会反复触发抓取或击掌邀请。任务打断后，旧停留不会重新启动互动。
- 工作中不启动挠痒、抓指针、模仿、绕圈和招呼；需要处理、失败或状态不明时让任务反馈接管。
- 原始按下、释放、点击、拖拽先交给既有控制器，再进入鼠标导演。点击仍然开合任务面板，拖拽不等待表演结束。
- 控制器确实接受播放后才记录冷却、次数和随机历史。被更重要动作阻止时不虚记“已经表演”。
- 减少动态模式压缩为约 140 毫秒的反馈。关闭鼠标互动、进入安静时段、打开右键菜单、窗口隐藏或任务变化会取消相关互动链。独立小游戏已移除。

## 接入与开销

`mouse-performances.js` 保存动作谱；`mouse-director.js` 识别手势并决定何时回应；`companion-avatar.js` 将真实输入、偏好及任务状态接入现有 `expression-controller.js`。

命中使用当前渲染身体的变换矩阵和实际移动中的手臂，适配缩放、转身和身体变形。每 45 毫秒最多采样一次，轨迹最多保留 36 点／1.7 秒；诊断只保留最近 24 次接受记录。使用已有原生鼠标输入，不增加全局鼠标钩子、网络服务或持久化鼠标轨迹。

## 验证入口

- `test/fixtures/mouse-interactions.html`：单角色、30 套逐套预览、真实手势练习与任务状态模拟。
- `test/fixtures/panel-system.html?companion=1`：生产界面和原生输入适配器，模拟任务数据。
- `test/mouse-director.test.cjs`：手势、冷却、变体、短链、抢占、工作状态。
- `test/expression-controller.test.cjs`：真实控制器拒绝、拖拽优先、减少动态和关闭偏好。
- `test/companion-mouse.pw.js`：生产输入的真实抚摸、落地、任务抢占和设置。
- `test/mouse-gestures.pw.js`：挠痒、绕圈、模仿、可见手部击掌、点击仍展开任务板。
- `test/mouse-gallery.pw.js`：30 套逐个完整播放、有限几何、单实例与静态检查图。
- `test/mouse-preview.pw.js`：预览切换、真实鼠标抚摸、任务优先和单实例。

预览和浏览器自动化不连接真实 Codex；原生冒烟另行核对桌面构建。测试不能替代不同电脑、触控板速度和长期使用的主观手感评估。
